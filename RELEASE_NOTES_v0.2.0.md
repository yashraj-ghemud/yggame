# yggame 0.2.0

This release packages the headless-first 2D game-development component library for Python and Pygame-CE.

## Included

The release includes the tested runtime core, rendering queues, scenes, camera, physics helpers, UI primitives, animation, inventory, dialogue, AI, pathfinding, saves, asset caching, five deterministic demo games, source documentation, and release automation.

## Validation

The release passed 36 tests, Ruff linting, strict mypy checks across 90 source files, distribution builds, and `twine check` for both the source archive and wheel.
